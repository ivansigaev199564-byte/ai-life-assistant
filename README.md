# AI Life Assistant

Персональный AI-слой поверх iPhone. Нажал кнопку действия, сказал, получил
тактильный отклик, готово. Разбор смысла и синхронизация происходят фоном.

Текущее состояние: **Этапы 1-3**. Голосовой захват, разбор мульти-интентов
и серверная часть с гибридным поиском написаны; развёртывание бэкенда ждёт
проекта Supabase.

## Требования

- Xcode 16 или новее (для веток под iOS 26 нужен Xcode 26)
- iOS 18.0 минимум, полный набор возможностей на iOS 26
- [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`

Проект в репозитории описан файлом `project.yml`, файла `.xcodeproj` в нём нет
намеренно: он генерируется и не порождает конфликтов слияния.

## Запуск

```
make generate   # создаёт AILifeAssistant.xcodeproj
make open       # открывает проект в Xcode
make test       # прогоняет юнит-тесты на симуляторе
```

Перед первым запуском на устройстве укажите свою команду разработчика
в настройках таргета и включите возможность App Groups с идентификатором
`group.com.ivans.ailifeassistant`.

## Что сделано

**Модели SwiftData**: `CaptureItem`, `Note`, `TaskItem`, `Reminder`, `Expense`,
`Person`, `Project`. Один захват может породить несколько сущностей, это основа
мульти-интента из Этапа 2. Перечисления хранятся строками, чтобы предикаты
и миграции не ломались.

**Голосовой захват**: микрофоном владеет `AudioEngineRecorder`, движки
распознавания его потребители. Реализованы два: `AppleSpeechRecognizer`
(текст по ходу речи, нужна явная локаль) и `WhisperKitRecognizer`
(определяет язык сам, работает по файлу после остановки). Переключение
в настройках, оба за протоколом `SpeechRecognizing`.

**Автостоп по тишине**: `VoiceActivityDetector` не зависит от AVFoundation,
принимает уровень сигнала и время, возвращает решение. Поэтому логика
полностью покрыта тестами без микрофона.

**Кнопка действия**: `QuickCaptureIntent` даёт тактильный отклик первым
действием, до любых проверок и ожиданий. Повторное нажатие останавливает
запись. Есть ярлыки Siri на русском и английском.

**Матрица возможностей**: `Capabilities` объединяет две оси, версию системы
и железо. Ключевой случай, который она закрывает: iPhone 13 на iOS 26 имеет
свежую ОС, но не имеет ни кнопки действия, ни Apple Intelligence.

### Разбор смысла (Этап 2)

Каскад из трёх уровней за общим протоколом: правила на регулярных
выражениях и словарях, локальная модель Apple Intelligence на iOS 26
и облачная модель со строгой схемой. Правила отрабатывают мгновенно,
и их результат сразу попадает в интерфейс; модели уточняют разбор,
когда пользователь уже видит записи.

Слияние результатов переносит идентификаторы совпавших сущностей,
поэтому уточнение обновляет созданную запись, а не создаёт дубль.
Сопоставление идёт по существу: сумма для расхода, время для
напоминания, общие слова заголовка для задачи.

Порог уверенности 0.7: ниже него сказанное сохраняется заметкой
с пометкой на проверку. Неверно созданная задача обходится
пользователю дороже, чем лишняя заметка.

### Бэкенд и поиск (Этап 3)

Схема Postgres с политиками доступа, полнотекстовый и векторный поиск,
объединённые через обратный ранг, и четыре функции: разбор через Claude,
генерация векторов, поиск и общие модули. Ключи моделей живут на сервере.

На стороне приложения: очередь операций, переживающая перезапуск,
двусторонняя синхронизация с разрешением конфликтов по времени правки,
вход через Apple с сессией в Keychain.

Подробности и инструкция по развёртыванию: `supabase/README.md`.

## Ограничения, о которых нужно знать

**Запись из интента без открытия приложения система не разрешает.** Кнопка
действия открывает приложение и сразу начинает слушать; тактильный отклик
успевает уйти в первые миллисекунды, поэтому ощущается как мгновенный.

**Новый Speech API из iOS 26 пока не подключён.** В `SpeechEngineFactory`
оставлена точка расширения. Реализацию нужно писать, сверяясь с заголовками
SDK в Xcode 26: публичной документации с точными сигнатурами на момент
написания нет, а гадать в production-коде нельзя.

**Модель WhisperKit весит сотни мегабайт** и скачивается по кнопке
в настройках, а не кладётся в бандл.

## Структура

```
project.yml                  описание проекта для XcodeGen
.github/workflows/ios.yml    сборка и тесты на macOS-раннере
AILifeAssistant/
  App/                       точка входа, контейнер данных, настройки, окружение
  Core/                      логи, доменные ошибки, возможности устройства
  Models/                    сущности SwiftData
  Voice/                     аудио, движки распознавания, детектор тишины, координатор
  Parsing/                   каскад разбора, экстракторы, материализация сущностей
  Network/                   клиенты моделей, схема запроса, конфигурация
  Sync/                      очередь, синхронизация, вход через Apple
  Search/                    гибридный поиск
  Design/                    токены, компоненты, визуализатор голоса
  Intents/                   App Intents, ярлыки Siri, тактильный движок
  Views/                     инбокс, экран записи, настройки
  Services/                  разрешения, хранилище аудио
  Resources/                 локализация ru/en, манифест приватности
AILifeAssistantTests/        юнит-тесты
```
